# Scenario Examples

This section contains scenario-focused configuration examples.

Each scenario folder includes:
- `sirenolite_config.json`: JSON overrides that are merged onto defaults.
- Optional CSV input profiles when the scenario depends on a specific resource/load shape.

Run any scenario from the repo root with:

```bash
sirenolite --config <path-to-scenario>/sirenolite_config.json
```

You can also load these same JSON files in the GUI using the `Configuration File (JSON)` controls on the Inputs tab.
